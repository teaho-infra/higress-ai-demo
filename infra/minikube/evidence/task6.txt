Task 6 — 数据面链路验证 (2026-09-17) ✅
=========================================
环境: minikube v1.37.0 (v1.39.0 CLI), Higress core 2.2.4 (源码构建镜像)

1. 宿主 downstream 起服:
   docker start wso2-demo-downstream → 0.0.0.0:9081
   GET 127.0.0.1:9081/healthz  → 200 {"status":"ok"}
   GET 127.0.0.1:9081/demo/time → 200

2. minikube 内访问宿主:
   host.minikube.internal -> 192.168.49.1

3. 创建 Service+Endpoints+Ingress (demo.local -> downstream-svc:9081):
   service/downstream-svc, endpoints/downstream-svc, ingress/demo-time created

4. 数据面转发 (增):
   curl -H 'Host: demo.local' 127.0.0.1:18080/demo/time
   → HTTP 200
   {"service":"downstream","server_time":"...","epoch_ms":...}   ✅ 真实转发到宿主容器

5. 收敛 (删):
   kubectl delete ingress demo-time → sleep 10
   curl -H 'Host: demo.local' 127.0.0.1:18080/demo/time → HTTP 404  ✅ 路由已撤销

结论: minikube容器 → host.minikube.internal(192.168.49.1) → 宿主downstream 全链路通。
      Higress 声明式 Ingress → controller → xDS → Envoy 动态增删收敛正常。
